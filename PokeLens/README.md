# ✨ PokéLens: מזהה פוקימונים על המסך

אפליקציית אנדרואיד שקוראת את המסך בזמן שאתה משחק Pokémon GO, מזהה את שם הפוקימון במפגש ומציגה בועה צפה עם מספר בפוקידקס, טיפוסים בעברית, חולשות (לפי מכפילי GO) ו-CP.

- OCR אופליין (Google ML Kit, המודל ארוז בתוך ה-APK)
- לא מתחבר לשרתים של Niantic, לא משנה את המשחק ולא לוחץ בשבילך. רק קורא את מה שמוצג על המסך
- דור 1–2 (251 פוקימונים), שמות באנגלית

## איך מקבלים APK בלי להתקין כלום על המחשב (GitHub)
1. פותחים ריפו חדש ב-github.com ומעלים אליו את כל התוכן של התיקייה הזאת (Add file ← Upload files). צריך לגרור גם את התיקייה `.github`.
2. לשונית **Actions** ← הבנייה (Build APK) רצה לבד, בערך 5–8 דקות.
3. נכנסים לריצה הירוקה ← **Artifacts** ← מורידים את `PokeLens-apk`, פותחים את ה-ZIP ובפנים יש `app-debug.apk`.
4. מעבירים לטלפון, מתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

## או עם Android Studio
File ← Open ← בוחרים את התיקייה ← Build ← Build APK(s).

## שימוש
הפעל ← מאשרים "הצגה מעל אפליקציות אחרות" ← הפעל שוב ← מאשרים הקלטת מסך ← עוברים למשחק. הבועה ניתנת לגרירה. עוצרים מההתראה.
